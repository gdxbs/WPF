PROTOCOL REFERENCE:
===================

Commands (backtick-prefixed, null-terminated):

  `join <room_id> <username>\0
    → Join a room with given username
    ← "You join @chatroom <room_id>\0"
    
  `start <room_id> <room_name>\0
    → Create a new room
    ← "Chatroom <room_id> started!\0"
    
  `list\0
    → List all rooms and users
    ← "room_name@id: user1@addr1 user2@addr2\n...\0"
    
  `quit\0
    → Leave current room
    ← "You quitted from chatroom...\0"
    
  `exit\0
    → Disconnect from server
    ← Server closes connection

Chat Messages (no prefix, null-terminated):

  "Hello everyone\0"
    → Send message to current room
    ← "username: Hello everyone\0"

Server Announcements (system messages):

  "Server: username joined us @chatroom room_id.\0"
  "Server: username quitted.\0"
